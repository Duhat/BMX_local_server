# BMX_local_server
📋 Краткая инструкция

1	Скачать репозиторий с GitHub (ZIP или git clone)

2	Установить Node.js с https://nodejs.org/

3	Перезагрузить компьютер

4	Открыть командную строку в папке проекта

5	Выполнить npm install

6	Выполнить npm start

7	Открыть http://localhost:3000/api/stats

Х Вы шикарны
